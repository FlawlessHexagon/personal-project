# Action Plan Framework Process

## Phases

| **Entry**   | **Description**                            |
| ----------- | ------------------------------------------ |
| ID          | Unique phase identifier (example: `AP-01`) |
| Title       | Name of the phase                          |
| Description | Purpose and scope of the phase             |
| Deadline    | Date by which the phase must be completed  |
| Status      | Task progression indicator                 |

## Tasks

| **Entry**               | **Description**                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| ID                      | Unique task identifier, combining phase and task numbers (example: `AP-01-01`)           |
| Title                   | Name of the task                                                                         |
| Description             | Work involved in the task                                                                |
| Linked Success Criteria | IDs of the product success criteria that the task contributes to achieving or evaluating |
| Target Completion Date  | Planned date for completing the task                                                     |
| Status                  | Task progression indicator                                                               |
