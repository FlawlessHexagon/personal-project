## General Description

A set of conditions that a product or feature must meet to be accepted.

## Classification
- Type: Criteria format
- Evidence status: Primary-source guidance; not a student success case or proof of assessment results
- Research date: 2026-10-06

## Source-Supported Description
Acceptance criteria define conditions that a feature or deliverable must satisfy to be accepted. [Atlassian](https://www.atlassian.com/work-management/project-management/acceptance-criteria/)

## Working Structure
Requirement → acceptance conditions → verification

The structure is a concise research adaptation, not a mandatory template quoted from the source.

## Strengths and Limitations; Analysis
- Strength: Clear boundaries make functional completion straightforward to evaluate.
- Limitation: A vague condition remains vague in a checklist; a passing feature may still be difficult to use.

## Project Relevance; Analysis
Suitable for basic note operations, data persistence, and specific offline behavior.

## Illustrative Application
> A saved note retains its title and content after the app is closed and reopened.

This example is authored for comparison. It is not taken from the source and does not establish the project's final criteria or thresholds.
