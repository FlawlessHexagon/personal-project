# [47] IoT Raspberry Pi Weather Station

## Classification
- Topic: Hardware & embedded systems / IoT sensor integration & Python
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn Raspberry Pi Linux administration, GPIO sensor interfacing, and Python data collection to monitor microclimates.
- Product: A functioning physical weather station integrating temperature, humidity, and atmospheric sensors with Python automation to log and display climate metrics.

## Why it succeeded
- The student structured an organized 4-week monthly calendar to pace hardware assembly and code writing.
- Physical environmental telemetry was verified through sustained observational testing.
- Official district showcase selection confirms working completion (no public IB score is available).

## Useful lesson
Physical computing projects benefit from decoupling sensor circuit testing from software logging to isolate hardware wiring faults early.
