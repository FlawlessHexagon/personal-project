# [21] Climatator 4D Climate Simulator

## Classification
- Topic: Embedded systems & IoT / physical computing & education
- Evidence status: Public GitHub repository documenting MYP Personal Project; showcase-only

## Project
- Goal: Combine web technologies, microcontrollers, and sensory actuators to build an immersive 4D environmental educational chamber.
- Product: A complete physical enclosure integrating Arduino, Raspberry Pi, Python, and Next.js to control synchronized heating, fans, lighting, audio, and video narration.

## Why it succeeded
Open-source codebase publication and multi-device hardware integration documentation are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Bridging physical microcontrollers (Arduino/Raspberry Pi) with modern web dashboards demonstrates sophisticated multi-tier technical capability.
