# [43] Turn-Based Digital Board Game

## Classification
- Topic: Software engineering / full-stack web game development
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn JavaScript, HTML5 canvas rendering, and game state mechanics to code a multiplayer board game.
- Product: A deployed two-player turn-based space strategy game on Replit featuring unique character abilities, dynamic asteroid hazards, and custom win conditions.

## Why it succeeded
- The student systematically organized development across language selection, physics rule definition, and web canvas rendering.
- Public deployment enabled live player testing and iterative rule balancing.
- District showcase publication serves as primary completion evidence (no public IB score is available).

## Useful lesson
Hosting interactive browser-based games on platforms like Replit provides frictionless access for peers to test and submit Criterion C usability feedback.
