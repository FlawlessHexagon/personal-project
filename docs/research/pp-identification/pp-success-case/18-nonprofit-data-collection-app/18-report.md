# [18] Pragathi NGO Data Collection App

## Classification
- Topic: Software engineering & database systems / club and NGO organizing
- Evidence status: Detailed student project blog documenting completed MYP Personal Project presentation; showcase-only

## Project
- Goal: Learn mobile programming in Java and database integration to replace slow paper-based student record collection for an education non-profit.
- Product: An Android Studio Java application backed by an online cloud database with automated CSV export for analytical reporting.

## Why it succeeded
School presentation completion and detailed public documentation of deployed NGO adoption are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Automating manual paper workflows for an organization provides immediate stakeholder feedback and tangible real-world impact.
