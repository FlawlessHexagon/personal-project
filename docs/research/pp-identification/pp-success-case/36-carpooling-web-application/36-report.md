# [36] Student Carpooling Web Application

## Classification
- Topic: Software engineering & web databases / full-stack school logistics
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Learn full-stack web architecture, database persistence, and user authentication to solve school commuting challenges.
- Product: A working carpooling web platform consisting of 762 lines of code across 24 files, featuring secure account registration, session login, city-based matching, and dynamic PHP/MySQL data retrieval.

## Why it succeeded
- The developer overcame full-stack data handling hurdles, connecting front-end forms with back-end database queries.
- Live hosting and public web deployment hurdles were documented and solved over months of iteration.
- Showcase inclusion confirms successful delivery and functionality (no public IB score is available).

## Useful lesson
Full-stack applications require realistic contingency buffers for deployment and hosting research, which often take longer than initial local coding.
