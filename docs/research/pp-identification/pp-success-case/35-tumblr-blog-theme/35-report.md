# [35] Tumblr Responsive Blog Theme

## Classification
- Topic: Software engineering / front-end web development (HTML, CSS, JavaScript)
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Acquire foundational web development capabilities in HTML, CSS, JavaScript, and graphic design to prepare for future computer science studies.
- Product: A complete custom-coded Tumblr blog theme featuring responsive layout styling, modular CSS variables, and dynamic user personalization options.

## Why it succeeded
- The student created a rigorous 4-part success criteria rubric across Aesthetics, User/Audience, Function, and Materials.
- Iterative debugging and multi-browser testing were documented across progressive development sprints.
- High school MYP showcase exhibition validates project completion (no public IB score is available).

## Useful lesson
Building themes for existing social platforms enforces real-world API constraints and dynamic template variables without requiring full back-end hosting setup.
