# [41] Python Multi-Game Arcade Suite

## Classification
- Topic: Software engineering / algorithmic Python programming
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn algorithmic programming fundamentals and text/graphical game architecture in Python over a six-month inquiry cycle.
- Product: A comprehensive three-game Python arcade suite featuring original adaptations of Oregon Trail, Blackjack card mechanics, and a turn-based combat system.

## Why it succeeded
- The student established iterative milestones spanning basic Python syntax through complex conditional game state loops.
- Multiple genre designs tested algorithmic randomization, player inventory tracking, and scoring systems.
- District showcase presentation validates full project completion (no public IB score is available).

## Useful lesson
Implementing multiple distinct game rule sets in Python tests different programming paradigms (card probabilities vs inventory resource management).
