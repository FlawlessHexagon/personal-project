# [56] Mobile First Aid Emergency App

## Classification
- Topic: Mobile application development & digital health / emergency response
- Evidence status: Official Overseas Family School MYP Personal Project Exhibition 2021 entry; showcase-only

## Project
- Goal: Program an intuitive mobile application providing quick, offline-ready first-aid protocols and emergency guidance during crises.
- Product: A portable first-aid smartphone application with categorized triage flowcharts, interactive CPR guidance, and rapid emergency dialing.

## Why it succeeded
- Ensured zero network dependency by caching all critical triage guides locally on device.
- Validated usability under time-pressured test simulations and earned MYP exhibition showcase selection (no public IB score is available).

## Useful lesson
Emergency applications require deterministic, zero-latency offline access and high-contrast typographic hierarchies for high-stress usability.
