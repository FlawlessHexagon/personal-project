# [10] UCC Textbook Exchange

## Classification
- Topic: School organizing / student marketplace platform
- Evidence status: Public GitHub repository explicitly created for MYP Personal Project; showcase-only

## Project
- Goal: Build a web-based community exchange platform to help Upper Canada College students buy, sell, and reuse course textbooks.
- Product: A React web application providing a centralized textbook listing and trade directory for students.

## Why it succeeded
Public repository release addressing a tangible school peer problem is the only success signal; selection and publication is the only success signal and no score is public.

## Useful lesson
Addressing practical inefficiencies in a student body generates instant user empathy and practical functional requirements.
