# [14] RevealTheIngredient Computer Vision App

## Classification
- Topic: Machine learning & computer vision / mobile health application
- Evidence status: Official Northville High School MYP showcase spotlight; showcase-only

## Project
- Goal: Build an iOS mobile application using computer vision and optical character recognition to detect hazardous ingredients on household chemical packaging.
- Product: RevealTheIngredient, a Swift/Xcode iOS app utilizing computer vision OCR and a toxicology database, achieving over 96% accuracy across 150 test labels.

## Why it succeeded
Showcase selection and publication on Northville High School MYP spotlight with quantitative test data are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Conducting controlled quantitative accuracy tests (e.g. 100 digital vs 50 physical trials) provides objective, indisputable Criterion C evaluation data.
