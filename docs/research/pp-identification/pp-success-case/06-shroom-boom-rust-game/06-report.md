# [06] Shroom Boom Rust Game

## Classification
- Topic: Software engineering / game development in Rust
- Evidence status: Public GitHub repository explicitly identifying MYP Personal Project game; showcase-only

## Project
- Goal: Master the Rust programming language and the Bevy ECS game engine by creating a complete multi-level action game.
- Product: A 12-level 2D game built in Rust using Bevy, featuring enemy AI, an upgrade shop system, custom pixel art, and score tracking.

## Why it succeeded
Public open-source release and playable game implementation are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Tackling a systems language like Rust for a personal project provides deep Criterion B skill growth when scoped to an achievable game loop.
