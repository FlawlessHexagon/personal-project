# [40] Python Game and ML Analytics Pipeline

## Classification
- Topic: Software engineering & machine learning / algorithmic development
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Investigate dual applications of Python across interactive GUI game development and machine learning data analysis.
- Product: A multi-component Python software suite featuring an interactive Pygame title (Tic-Tac-Toe) and an NBA sports statistical machine learning data model.

## Why it succeeded
- The student systematically planned learning phases across IDLE environment configuration, Pygame multimedia handling, and statistical modeling algorithms.
- Detailed investigation records guided model library selection and game loop logic.
- High school showcase exhibition demonstrates complete delivery (no public IB score is available).

## Useful lesson
Comparing machine learning data processing with interactive game event loops within one language deepens understanding of Python versatility.
