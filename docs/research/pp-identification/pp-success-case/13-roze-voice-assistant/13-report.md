# [13] ROZE Voice Assistant

## Classification
- Topic: Artificial intelligence / speech recognition & automation
- Evidence status: Public GitHub repository documenting 2018 IB MYP Personal Project; showcase-only

## Project
- Goal: Learn Python, audio processing, and automated task execution by developing a desktop voice assistant.
- Product: ROZE, a Python voice assistant capable of speech recognition, text-to-speech feedback, system commands, and web automation.

## Why it succeeded
Completed open-source Python codebase publication is the only success signal; selection and publication is the only success signal and no score is public.

## Useful lesson
Building conversational interfaces teaches robust input handling, external API integration, and user error tolerance.
