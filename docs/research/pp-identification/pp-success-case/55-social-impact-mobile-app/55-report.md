# [55] Action-Oriented Mobile Impact App

## Classification
- Topic: Mobile app development & environmental tech / civic action
- Evidence status: Official Overseas Family School MYP Personal Project Exhibition 2021 entry; showcase-only

## Project
- Goal: Develop a cross-platform mobile application empowering youth to track and execute environmental impact initiatives.
- Product: An interactive mobile application featuring sustainable habit logging, impact metrics calculation, and community milestone challenges.

## Why it succeeded
- Designed clean mobile interaction flows and gamified micro-actions that sustained active student testing.
- Met all technical success criteria and was featured in the institutional MYP video showcase (no public IB score is available).

## Useful lesson
Breaking abstract sustainability goals into verifiable, daily quantifiable micro-actions dramatically increases user follow-through in mobile tools.
