# [27] MIT App Inventor Mobile Utility

## Classification
- Topic: Software engineering / mobile application development
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn event-driven visual programming and mobile interface design using MIT App Inventor to build a student utility app.
- Product: A completed mobile utility application and presentation documenting mobile app architecture and logic workflows.

## Why it succeeded
District MYP STEM showcase presentation selection is the only success signal and no score is public.

## Useful lesson
Visual block-based tools like MIT App Inventor allow beginners to master computational logic and UX flows before transitioning to raw code.
