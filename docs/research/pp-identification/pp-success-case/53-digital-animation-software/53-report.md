# [53] 2D Digital Animation Software

## Classification
- Topic: Software engineering & computer graphics / animation tooling
- Evidence status: Official Overseas Family School MYP Personal Project Exhibition 2021 entry; showcase-only

## Project
- Goal: Program custom standalone animation software to streamline the frame-by-frame 2D animation process for digital artists.
- Product: A functional 2D animation application providing canvas drawing tools, onion skinning, timeline playback, and frame management.

## Why it succeeded
- Implemented real-time graphical canvas rendering and responsive UI controls without external bloated frameworks.
- The working application was showcased at the schoolwide MYP Personal Project exhibition (no public IB score is available).

## Useful lesson
Structuring an animation tool around efficient canvas state serialization ensures smooth playback across high frame counts.
