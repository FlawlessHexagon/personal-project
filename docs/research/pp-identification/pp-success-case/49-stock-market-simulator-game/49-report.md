# [49] Student Stock Market Simulator Game

## Classification
- Topic: Software engineering & financial technology / educational game design
- Evidence status: Official Overseas Family School MYP Personal Project Exhibition 2021 entry; showcase-only

## Project
- Goal: Create a student-friendly stock market simulator game to teach basic financial literacy and equity investing dynamics.
- Product: An interactive simulated trading game replicating market price fluctuations, portfolio tracking, and trade execution for student learning.

## Why it succeeded
- The student translated complex financial mechanisms into accessible game loops with clear feedback states.
- The project successfully satisfied Criterion C delivery and was selected for the official schoolwide MYP exhibition video showcase (no public IB score is available).

## Useful lesson
Simulating real-world dynamic systems through gamified mechanics lowers cognitive barriers for student audiences while providing measurable user engagement.
