# [12] MYP Grade Calculator

## Classification
- Topic: School organizing / educational utility software
- Evidence status: Public GitHub repository documenting MYP Personal Project tool; showcase-only

## Project
- Goal: Create a software tool to help Middle Years Programme students calculate and forecast their overall MYP criterion and subject scores.
- Product: A desktop software tool implementing MYP assessment boundary logic and grade computation tables.

## Why it succeeded
Public code release and software implementation are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Codifying the rules of the MYP curriculum into software ensures deep alignment between the student creator and their academic environment.
