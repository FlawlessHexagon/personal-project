# [19] Accessible Python Virtual Assistant

## Classification
- Topic: Software engineering / accessibility & Python tooling
- Evidence status: Student portfolio website documenting completed MYP Personal Project; showcase-only

## Project
- Goal: Learn Python programming and software accessibility design by creating a standalone desktop virtual assistant.
- Product: A Python virtual assistant featuring interactive text and voice games (Magic 8-ball, Lucky 7), synchronized dual voice/text output, and keyboard fallback navigation.

## Why it succeeded
Portfolio publication and independent project completion are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Prioritizing accessibility through dual multimodal outputs (spoken audio plus terminal text) strengthens Criterion B technical and design skills.
