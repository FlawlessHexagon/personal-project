# [34] Impromptu Speaking Web Platform

## Classification
- Topic: Software engineering & web design / public speaking educational resource
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Master responsive web design principles and front-end layout techniques to build an organized educational platform.
- Product: Impromptu 101 (impromptu101.com), a public educational website providing an A-E presentation guide, prompt generators, speech practice resources, and user feedback forms.

## Why it succeeded
- The student designed an explicit 4-tier rubric (Aesthetics, User/Audience, Content/Function, Impact) scored from 1 to 8.
- Traffic metrics demonstrated over 300 active visitors accessing the speech training materials.
- Official showcase selection serves as the primary verification signal (no public IB score is available).

## Useful lesson
Defining quantitative user reach metrics in Criterion A success criteria turns abstract web design goals into measurable Criterion C evaluation data.
