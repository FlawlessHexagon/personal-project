# [44] Robotic Vacuum Embedded Game System

## Classification
- Topic: Robotics & embedded programming / hardware abstraction & game logic
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Master the iRobot programming interface and sensor APIs to transform household hardware into an interactive gaming device.
- Product: The Hangman Trials, an embedded game system programmed on an iRobot platform utilizing onboard sensors, motor actuation, and audiovisual feedback loops.

## Why it succeeded
- The student overcame sparse third-party API documentation through empirical trial-and-error hardware experiments.
- Self-evaluation scored creativity and hardware utilization at maximum rubric levels.
- Official showcase display validates working physical implementation (no public IB score is available).

## Useful lesson
Repurposing consumer robotics via native APIs requires deep resilience and creative problem-solving when formal tutorials are limited.
