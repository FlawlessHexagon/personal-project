# [38] EEG Brainwave Monitoring System

## Classification
- Topic: Hardware & software engineering / biomedical signal processing
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Learn neurological signal acquisition and Python data visualization by pairing EEG hardware with a single-board computer.
- Product: iReadYourMind, an embedded sensor workstation connecting a Muse EEG headband to a Raspberry Pi 3 to stream, filter, and graph neural wave bands (Beta, Alpha, Theta, Delta) in real time.

## Why it succeeded
- The student formulated SMART milestones for Bluetooth telemetry handshake, signal processing, and visual charting.
- Practical troubleshooting overcome microcomputing interface errors and sensor latency.
- Official showcase display validates successful prototyping (no public IB score is available).

## Useful lesson
Interfacing consumer biomedical sensors with single-board computers requires strict signal filtering to separate genuine neural data from ambient electrical noise.
