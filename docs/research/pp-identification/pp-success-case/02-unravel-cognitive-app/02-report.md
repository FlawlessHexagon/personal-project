# [02] Unravel Cognitive Skills App

## Classification
- Topic: Software engineering / mobile healthcare & education
- Evidence status: School prodigy profile documenting student personal project; showcase-only

## Project
- Goal: Develop a digital application to train and enhance cognitive skills in young children.
- Product: Unravel, a mobile application designed for cognitive enhancement with documented distribution.

## Why it succeeded
Public showcase selection and student profile publication by Pathways School Gurgaon are the primary success signals, reporting over 600 downloads; selection and publication is the only success signal and no score is public.

## Useful lesson
Focusing on a concrete developmental problem enables meaningful external user testing and tangible post-launch adoption metrics.
