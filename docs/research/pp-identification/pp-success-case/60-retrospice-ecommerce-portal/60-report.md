# [60] RetroSpice E-Commerce Web Store

## Classification
- Topic: Web engineering & digital commerce / business technology
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 Fabrication entry; showcase-only

## Project
- Goal: Develop and deploy a fully functional e-commerce web platform integrating online storefront architecture, inventory catalogs, and pricing models.
- Product: RetroSpice, a live online boutique web store featuring branded merchandise catalogs, responsive cart navigation, and digital checkout flows.

## Why it succeeded
- Integrated product photography, digital catalog structures, and commercial checkout pipelines into a cohesive platform.
- Exhibited at the Mira Loma High School MYP Personal Project Showcase (no public IB score is available).

## Useful lesson
Building an e-commerce platform requires tight alignment between digital inventory data structures and responsive user checkout interfaces.
