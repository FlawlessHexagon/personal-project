# [32] Arduino IoT Elderly Fall Detector

## Classification
- Topic: Embedded systems & IoT / assistive healthcare hardware
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2022/2023 STEM entry; showcase-only

## Project
- Goal: Engineer a wearable electronic safety device using an accelerometer and Arduino microcontroller to detect sudden falls in elderly individuals.
- Product: A working wearable fall detection device programmed in Arduino C++ with threshold trigger algorithms and alert signaling.

## Why it succeeded
District MYP STEM showcase publication is the only success signal and no score is public.

## Useful lesson
Sensor threshold calibration requires empirical trial data across different movement types to avoid false positive alarms.
