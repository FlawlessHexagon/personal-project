# [05] Cogni+OS Autism Interface Prototype

## Classification
- Topic: Software engineering / assistive technology & human-computer interaction
- Evidence status: Public GitHub repository documenting MYP Personal Project with expert collaboration; showcase-only

## Project
- Goal: Design and build an operating system interface prototype to help children with Level 2 Autism Spectrum Disorder use desktop systems while minimizing sensory hypersensitivity.
- Product: A functional Swift-based prototype executable for macOS with tailored visual ergonomics, developed in consultation with university and clinical experts.

## Why it succeeded
Public code release and expert consultation documentation are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Consulting domain specialists (behavior analysts and professors) transforms technical software into rigorously justified assistive technology.
