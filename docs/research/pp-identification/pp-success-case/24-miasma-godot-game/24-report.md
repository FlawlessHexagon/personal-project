# [24] Miasma Godot Adventure Game

## Classification
- Topic: Software engineering / game design & GDScript
- Evidence status: Public GitHub repository explicitly created for MYP Personal Project; showcase-only

## Project
- Goal: Master the Godot engine, 2D physics, and GDScript programming to create a standalone playable narrative adventure game.
- Product: Miasma, a completed 2D video game developed with Godot featuring player movement, world state management, and collision mechanics.

## Why it succeeded
Open-source codebase release and repository publication are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Open-source game engines like Godot allow rapid iteration while demanding rigorous code organization for scene trees and game physics.
