# [09] Bhavya Interactive Chess Catalogue

## Classification
- Topic: Software engineering / educational web platform
- Evidence status: Public GitHub repository documenting MYP Personal Project web application; showcase-only

## Project
- Goal: Learn front-end web development, responsive CSS, and DOM scripting to build an interactive educational resource for chess learners.
- Product: A multi-page responsive web resource featuring rules explanation, custom Blender 3D chess graphics, and interactive opening move trainers.

## Why it succeeded
Open-source codebase completion and documentation are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Breaking complex domains (like chess openings) into dedicated JavaScript-driven interactive trainers makes educational web projects highly engaging.
