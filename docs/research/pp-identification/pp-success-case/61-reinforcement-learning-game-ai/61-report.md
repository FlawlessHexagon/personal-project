# [61] Deep Reinforcement Learning Game-Playing Agent

## Classification
- Topic: Artificial intelligence & machine learning / reinforcement learning
- Evidence status: Primary open-source codebase & recorded video demonstrations; showcase-only

## Project
- Goal: Research Sutton & Barto RL fundamentals to create a custom 2D simulation environment and train an autonomous AI agent using neural networks.
- Product: An original Python game environment alongside Deep Q-Network (DQN) agents trained to navigate obstacles and optimize survival rewards.

## Why it succeeded
- Engineered custom reward functions, state-space vector arrays, and multi-layer neural networks from scratch.
- Published reproducible code and multi-agent training demonstration logs (no public IB score is available).

## Useful lesson
Normalizing input observation arrays and penalizing idle actions stabilizes deep reinforcement learning training convergence in custom environments.
