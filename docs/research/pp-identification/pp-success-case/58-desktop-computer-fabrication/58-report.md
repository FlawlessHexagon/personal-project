# [58] Custom Desktop Workstation Architecture

## Classification
- Topic: Computer engineering & hardware architecture / systems integration
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Master personal computer architecture, multi-bus communication, and cooling optimization to construct a high-performance workstation.
- Product: A custom-built, fully operational desktop computer configured for demanding digital media workflows and academic software.

## Why it succeeded
- Executed component compatibility analysis, managed power rail allocation, and verified POST and OS installation without component damage.
- Showcased in the Mira Loma High School MYP STEM exhibition (no public IB score is available).

## Useful lesson
Stepwise out-of-chassis testing (breadboarding) prior to permanent installation minimizes troubleshooting time for faulty motherboard headers or bad RAM seating.
