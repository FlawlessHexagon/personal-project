# [11] LibreHunt Linux Distro Selector

## Classification
- Topic: Software engineering / open-source utility
- Evidence status: Public GitHub repository documenting MYP Personal Project featured on major tech media; showcase-only

## Project
- Goal: Design a client-side web utility to guide newcomers in selecting an appropriate Linux distribution based on their hardware and preferences.
- Product: LibreHunt, a client-side JavaScript recommendation engine that filters and presents Linux distributions.

## Why it succeeded
Public deployment and external tech media recognition (featured on Forbes) are the primary success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Creating tools that solve real decision hurdles in technical communities can achieve genuine organic adoption far beyond school walls.
