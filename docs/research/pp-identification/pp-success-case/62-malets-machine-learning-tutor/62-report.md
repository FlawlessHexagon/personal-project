# [62] MALETS Machine Learning Interactive Tutorial

## Classification
- Topic: Computer science education & GUI engineering / machine learning pedagogy
- Evidence status: Primary open-source software release; showcase-only

## Project
- Goal: Develop an interactive desktop application that introduces non-technical secondary students to foundational machine learning concepts.
- Product: MALETS (Machine Learning Tutorial Software), a Python and PyQt desktop program featuring visual algorithm walkthroughs and interactive datasets.

## Why it succeeded
- Combined complex statistical learning principles with an intuitive, guided graphical interface.
- Deployed a complete standalone application bundle with bundled tutorial curricula (no public IB score is available).

## Useful lesson
Decoupling educational explanatory text from algorithmic execution logic allows educators to update curriculum content without refactoring interface code.
