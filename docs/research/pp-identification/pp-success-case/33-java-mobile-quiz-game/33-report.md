# [33] Java Mobile Quiz Game

## Classification
- Topic: Software engineering / mobile game programming in Java
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Learn object-oriented programming fundamentals in Java to develop a custom mobile trivia application.
- Product: A functional mobile quiz game exploring regional vocabulary ("British vs American Quiz") featuring repository integration and gameplay scoring.

## Why it succeeded
- The student structured a staged action plan moving from web scripting basics to Java class architecture and repository code comprehension.
- Game mechanics were iteratively tested against predefined success criteria before final deployment.
- Featured selection in the school MYP Personal Project Showcase demonstrates completed delivery (no public IB score is available).

## Useful lesson
Forking or referencing existing open-source code repositories provides practical architectural scaffolding for learning a statically typed language like Java.
