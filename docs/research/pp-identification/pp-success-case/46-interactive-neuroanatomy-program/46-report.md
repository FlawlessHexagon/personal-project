# [46] Interactive Neuroanatomy Software

## Classification
- Topic: Software engineering / neuroscience & pedagogical software
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Combine computer programming with neurological research to create an interactive anatomical learning application.
- Product: A custom interactive educational software application mapping cerebral lobes, functional neuroanatomy, and physiological descriptions.

## Why it succeeded
- The student developed explicit success criteria requiring identification and descriptions for all anatomical cerebral lobes.
- Graphic assembly and user click detection were implemented within platform constraints.
- Inclusion in the district STEM showcase establishes finished execution (no public IB score is available).

## Useful lesson
Building specialized subject tutorials requires balancing technical code modularity with rigorous scientific accuracy in informational assets.
