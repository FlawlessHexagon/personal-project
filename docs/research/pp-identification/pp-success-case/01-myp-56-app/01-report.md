# [01] MYP 56 App

## Classification
- Topic: Educational technology / mobile application
- Evidence status: Project-specific public App Store release; showcase-only

## Project
- Goal: Build an offline-first iOS preparation and productivity application tailored specifically to IB MYP students.
- Product: MYP 56, an iOS mobile application featuring practice exam papers and a Personal Project companion process journal tagged to MYP criteria.

## Why it succeeded
Selection and publication on the Apple App Store is the only success signal and no score is public.

## Useful lesson
Designing specifically around MYP assessment structures provides immediate utility to peers and yields clear, criterion-aligned product criteria.
