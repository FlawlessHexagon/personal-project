# [42] Educational Deforestation Game in Python

## Classification
- Topic: Software engineering / educational technology & environmental simulation
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn Python programming to develop an interactive pedagogical game simulating environmental consequences of deforestation.
- Product: A playable Python simulation game where player management choices directly influence forest preservation and ecosystem health.

## Why it succeeded
- The developer linked programming mechanics with environmental science research across Criterion A planning stages.
- Player feedback loops demonstrated how choices impacted conservation variables.
- Official district STEM showcase selection confirms successful exhibition (no public IB score is available).

## Useful lesson
Embedding educational objectives directly into game state variables makes software an active instructional vehicle rather than a passive quiz.
