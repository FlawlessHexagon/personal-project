# [54] Migrant Worker Support Web Platform

## Classification
- Topic: Web development & civic technology / community organizing
- Evidence status: Official Overseas Family School MYP Personal Project Exhibition 2021 entry; showcase-only

## Project
- Goal: Build an accessible, multi-lingual informational web portal to assist foreign migrant workers in navigating legal rights and services.
- Product: A comprehensive responsive website centralizing essential worker welfare resources, helpline directories, and educational content.

## Why it succeeded
- Addressed documented community barriers by prioritizing intuitive mobile navigation and multilingual content delivery.
- Successfully deployed the production portal, earning public showcase honors (no public IB score is available).

## Useful lesson
Civic technology tools succeed when information architecture is stripped of technical and linguistic jargon for vulnerable end-users.
