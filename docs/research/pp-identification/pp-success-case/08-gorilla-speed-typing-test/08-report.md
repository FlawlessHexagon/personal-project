# [08] Gorilla Speed Typing Platform

## Classification
- Topic: Software engineering / web development & algorithms
- Evidence status: Public GitHub repository documenting MYP Personal Project web application; showcase-only

## Project
- Goal: Learn React and Next.js to develop a high-performance web platform measuring typing speed and clicking metrics.
- Product: Gorilla Speed, a full Next.js web application implementing randomized word generation and real-time CPS/WPM calculation algorithms.

## Why it succeeded
Public web application code repository and functional algorithm deployment are the only success signals; selection and publication is the only success signal and no score is public.

## Useful lesson
Clear mathematical formulation of product metrics (e.g. WPM and CPS formulas) simplifies user interface testing and verification.
