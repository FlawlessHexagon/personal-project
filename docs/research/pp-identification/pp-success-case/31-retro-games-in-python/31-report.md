# [31] Retro Game Suite in Python

## Classification
- Topic: Software engineering / game programming & Pygame
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2022/2023 STEM entry; showcase-only

## Project
- Goal: Master Python data structures, game loops, and collision math by recreating classic retro arcade games.
- Product: A suite of functioning retro arcade games implemented in Python featuring state management, scoring, and sprite animations.

## Why it succeeded
District MYP STEM showcase publication is the only success signal and no score is public.

## Useful lesson
Replicating established retro game rules removes ambiguous gameplay design questions, letting the student focus purely on clean code implementation.
