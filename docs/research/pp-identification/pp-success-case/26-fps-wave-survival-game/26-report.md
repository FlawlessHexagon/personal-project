# [26] First-Person Shooter Wave Survival Game

## Classification
- Topic: Software engineering / 3D game development
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn 3D game engine programming, vector math, and enemy wave spawning algorithms to build a 3D shooter.
- Product: A functional first-person shooter survival game featuring wave mechanics, projectile collision, and scoring systems.

## Why it succeeded
Selection and publication in the district MYP STEM showcase is the only success signal and no score is public.

## Useful lesson
Implementing core mechanics in distinct sprints (movement, shooting, enemy AI, wave logic) keeps ambitious 3D game projects manageable.
