# [39] Unity 2D Platformer Game Engine

## Classification
- Topic: Software engineering / game development & C# scripting
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Master the Unity engine pipeline, 2D physics kinematics, and C# scripting to produce a polished platforming title.
- Product: G.R.A.P.P.L.E., a fully playable 2D platformer video game providing 10-15 minutes of gameplay built on custom physics mechanics and level design.

## Why it succeeded
- The developer maintained steady progress through daily micro-milestones and structured C# code iteration.
- Rigorous success criteria scored gameplay fluidity, audio atmosphere, and level progression.
- Selection and display in the district MYP showcase confirm completion (no public IB score is available).

## Useful lesson
Committing to small daily coding targets prevents procrastination during large engine-based software projects and keeps feature creep under control.
