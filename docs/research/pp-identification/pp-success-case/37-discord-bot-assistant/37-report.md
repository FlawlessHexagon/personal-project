# [37] Discord Community Management Bot

## Classification
- Topic: Software engineering & API integration / Node.js & Discord.js
- Evidence status: Official Mira Loma High School MYP Personal Project Showcase 2022/23 entry; showcase-only

## Project
- Goal: Learn asynchronous JavaScript programming, Node.js environment configuration, and bot event handling.
- Product: Taemnie, an interactive Discord bot integrating command listeners, environment security via dotenv, and community engagement features.

## Why it succeeded
- When Discord.js updated from v13 to v14 breaking earlier code, the student refactored syntax and adapted to the breaking API changes.
- Detailed rubrics evaluated token privacy, uptime, and command response handling.
- Official showcase exhibition establishes project completion (no public IB score is available).

## Useful lesson
Managing third-party library dependencies requires tracking breaking semantic version changes, demonstrating resilient problem-solving in Criterion B.
