# [45] Automated Weather Data Bot

## Classification
- Topic: Software engineering & cloud automation / Python & REST APIs
- Evidence status: Official San Juan USD MYP Personal Project Showcase 2020/2021 STEM entry; showcase-only

## Project
- Goal: Learn Python scripting, external weather REST APIs, and automated cloud scheduling.
- Product: An automated Python service deployed on PythonAnywhere that fetches real-time meteorological data and publishes scheduled daily weather forecasts on Twitter.

## Why it succeeded
- The developer successfully configured cloud crons and API authentication tokens for unmanned execution.
- Live logs confirmed seven consecutive days of automated, error-free forecast broadcasting.
- District MYP showcase publication demonstrates complete delivery (no public IB score is available).

## Useful lesson
Cloud-scheduled micro-services provide an ideal introduction to REST API authentication, environment variables, and headless cron tasks.
