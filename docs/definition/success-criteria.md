### SC-01: Basic application functions - Acceptance criteria

| **ID**  | **Title** | **Description**                                                      | **Status**  |
| ------- | --------- | -------------------------------------------------------------------- | ----------- |
| SC-01-1 | Create    | Saving a new note makes it appear in the notes list.                 | Not checked |
| SC-01-2 | View      | Opening a saved note displays its saved contents.                    | Not checked |
| SC-01-3 | Edit      | Saving changes and reopening the note displays the updated contents. | Not checked |
| SC-01-4 | Delete    | Deleting a note removes it from the notes list.                      | Not checked |

### SC-02: Data preservation and recovery - Acceptance criteria

| **ID**  | **Title**        | **Description**                                                      | **Status**  |
| ------- | ---------------- | -------------------------------------------------------------------- | ----------- |
| SC-02-1 | Export           | Users can export selected notes to a file in a location they choose. | Not checked |
| SC-02-2 | Export integrity | Exported file preserves every selected note’s contents.              | Not checked |
| SC-02-3 | Import           | Users can import a previously exported file into the app.            | Not checked |
| SC-02-4 | Import integrity | Imported notes retain their contents.                                | Not checked |
