# Phase 02: Define Product Success Criteria

## Objective

Establish measurable criteria for evaluating the completed product.

## Steps

1. Research Success Criteria Format

> Investigate different success criteria formats and compare their strengths, limitations, and suitability for this project.

2. Design a Hybrid Format Matching Use Case

> Combine suitable elements from the researched formats into a structure tailored to this project’s evaluation needs.

3. Develop Product Success Criteria

> Define measurable criteria aligned with the project definition.
